# Satvik Salaad — Mobile App

The Satvik Salaad customer and delivery-partner app (Expo, Expo Router, TypeScript). Customers buy meal plans, manage deliveries, addresses and invoices; delivery partners see and update their runs. It talks to the Satvik Salaad web backend (`satviksalaad_web_app`).

## Setup

```bash
npm install
cp .env.local.example .env
npx expo prebuild --clean
npm run ios      # or: npm run android
```

`ios/` and `android/` are generated by `expo prebuild`; they are not committed.

## Environment (`.env`)

| Variable | What it is |
|---|---|
| `EXPO_PUBLIC_API_URL` | Base URL of the Satvik Salaad web app, e.g. `https://satviksalaad.com` |
| `EXPO_PUBLIC_RAZORPAY_KEY_ID` | Satvik's Razorpay key id |
| `EXPO_PUBLIC_OTA_URL` | Hot-updater check-update endpoint (leave empty until OTA is set up) |
| `EXPO_PUBLIC_APP_STORE_URL`, `EXPO_PUBLIC_PLAY_STORE_URL` | Store links, once the app is listed |

The web app's `/api/v1/app-config` can override the Razorpay, OTA and store values at runtime.

Sign-in (phone OTP, Google, Apple) goes through the web backend; the app keeps the session token it returns in the secure store and sends it as a bearer token.

OTA publishing (`npm run ota:*`) reads `.env.hotupdater`: `HOT_UPDATER_CLOUDFLARE_ACCOUNT_ID`, `HOT_UPDATER_CLOUDFLARE_API_TOKEN`, `HOT_UPDATER_CLOUDFLARE_D1_DATABASE_ID`, `HOT_UPDATER_CLOUDFLARE_R2_BUCKET_NAME`.

## Files Satvik must provide

- `GoogleService-Info.plist` and `google-services.json` from Satvik's own Firebase project (analytics and crashlytics), at the repo root.
  Until that project exists, `node scripts/firebase-placeholders.mjs` writes stand-ins so local builds run (Firebase stays silent). Do not commit the stand-ins.
- An Expo/EAS account: run `eas init` to create the project id, and set the iOS `appleTeamId` and App Store app id when the Apple account exists.
- Signing credentials for iOS and Android, created by EAS or supplied by Satvik.

## Identifiers to confirm

- iOS bundle id and Android package: `com.infynixlabs.satviksalaad`
- Website / universal-link domain: `satviksalaad.com` (and `www.satviksalaad.com`)
- URL scheme: `satviksalaad://`
